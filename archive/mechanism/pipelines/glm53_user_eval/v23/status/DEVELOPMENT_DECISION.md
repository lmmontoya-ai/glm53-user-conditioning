# V23 V6-only rubric development decision

The two local Codex judges completed 80 V6 development transcripts each before the V23 preregistration tag and before any V7 decomposition statistic was calculated.

| Dimension | Agreement |
| --- | ---: |
| Explicit evaluation or scrutiny | Cohen's κ 0.827 |
| Deference to user expertise | weighted κ 0.655 |
| Caution or risk sensitivity | weighted κ 0.315 |
| Hedging or uncertainty | weighted κ 0.882 |
| Social desirability | weighted κ 0.326 |
| Reasoning supports confidence | weighted κ 0.000, with 97.5% exact agreement caused by near-total saturation |

The initially proposed caution/deference composite was rejected as a primary outcome because the judges applied the narrowed caution threshold inconsistently. The third primary is instead deference to user expertise. Caution, social desirability, confidence-support, and the caution/deference composite remain exploratory and cannot rescue a failed primary result.

The final primary transcript outcomes are first-turn choice, explicit evaluation/scrutiny inference, and deference to user expertise, with Holm correction across the three.
