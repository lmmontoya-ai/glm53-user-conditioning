# GLM-5.3 V23 — Decision versus self-calibration

V23 is an offline decomposition of the locked V7 four-population interaction. It makes no new GLM calls and spends nothing on RunPod. V6 is used only for parser and rubric development; V7 supplies the locked analysis.

The deterministic branch asks whether the identity interaction appears in the first yes/no choice or persists in confidence after accounting for that choice. The annotation branch applies independent, non-fast Luna-max and Terra-high judgments to 2,000 profile-blinded transcripts. A 160-row packet is prepared for Luis, but automated code never marks that human review complete.

Commands are exposed by `run.py`. V7 analysis and judgments refuse to run unless `glm53-user-eval-v23-preregistered` exists and contains the exact active preregistration.
