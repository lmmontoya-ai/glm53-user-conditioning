# GLM-5.3 V18 B300 execution

V18 is an infrastructure-only continuation of the preregistered V17 Hua-style
causal experiment. V17 ended before its first model forward because the
requested GPU topology could not be allocated. V18 changes only the paid
runtime to exactly two NVIDIA B300 SXM6 AC GPUs and increases the bounded
compute allowance to match their live price.

The V17 prompts, directions, conditions, estimands, gates, stopping rules, and
analysis code are immutable inputs. V18 may not repair or reinterpret a failed
scientific gate.
